# dsh-tallybook

给 DSH（DeepSeek Harness）Web 界面加一个「用量统计」面板：看自己每天花了多少钱、token 都花在哪，比在开放平台里翻图表顺手一点。名字叫 tallybook，就是"记账本"的意思。

装了它之后，左侧栏会多一个图表图标，点进去是这样一个页面：

- 顶部几张卡：累计消费、本月消费、月均、日均、累计请求。
- 一张大图：逐日消费（橙色实线，右轴金额）和逐日 token（左轴对数，含缓存命中 / 未命中 / 输出）。每屏可以选 2 个月 / 3 个月 / 6 个月 / 1 年，往左拖能看到更早的记录。
- 按月统计：选一个月份，看该月消费、日均、截至该月累计，以及该月的逐日曲线；表格里每个月的环比、同比。
- 按年统计：年度汇总和年度曲线，表格带同比。
- 右上角两个按钮：把逐日明细复制到剪贴板（Tab 分隔，粘进 Excel/WPS 直接分列），或者导出成 CSV。

## 数据从哪来

数据来自你自己已登录的 DeepSeek 开放平台账号（`platform.deepseek.com`），由本机的 DSH 进程读取：

- `users/get_user_summary` —— 累计消费
- `usage/cost`、`usage/amount` —— 每日消费与 token 构成

账号令牌只在 DSH 主进程里使用，不会发给浏览器，也不会写到任何日志里；浏览器只拿到汇总后的数字。快照会缓存在 `DSH_HOME/storages/deepseek-usage-stats/snapshot.json`，过期后先显示旧数据、后台再刷新。

## 安装

插件是标准的 DSH bundle，本地目录即可安装：

1. 在 DSH 的「设置 → 插件 → 插件列表」里选择本地目录安装；或
2. 用命令行：`dsh plugin --profile <你的 profile> add link:<本目录绝对路径>`。

装完重启 DSH，左侧栏就会出现入口。需要先在 DSH 里登录 DeepSeek 账号，否则面板会提示未登录。

## 已知限制

- 用的是平台网页自己的内部接口，不是公开 API；平台改字段就得跟着改。
- 日期按平台返回的日切分展示，不做时区换算。
- 账号没有满一年时，同比一律按「上年为 0」处理：本年有消费显示 100%，两边都是 0 显示 0%。
